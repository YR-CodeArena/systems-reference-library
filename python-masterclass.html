1.1 Understanding the Python Execution Architecture

Python is a high-level, interpreted, dynamically-typed, multi-paradigm programming language created by Guido van Rossum and released in 1991. Unlike statically compiled languages such as C, C++, or Rust, which convert source code directly into architecture-specific machine code binaries before execution, Python utilizes a multi-tier compilation and execution pipeline:

  • Source Code Parsing: The Python interpreter parses human-readable .py source files, verifying lexical syntax and building an Abstract Syntax Tree (AST).
  • Bytecode Compilation: The AST is compiled into platform-independent intermediate instructions called Bytecode ( .pyc files stored automatically inside the __pycache__ directory). Bytecode reduces execution overhead for subsequent script runs.
  • Python Virtual Machine (PVM): The PVM is an execution engine loop that reads bytecode instructions sequentially and translates them into CPU-level instructions for the host operating system.

This execution pipeline provides immense cross-platform portability across Windows, macOS, Linux, and embedded systems, allowing code written on one operating system to execute seamlessly on any other operating system equipped with a compatible Python interpreter.

1.2 Interpreter Installation & Environment Configuration

To establish a production-ready Python development workspace, developers configure two essential software tools:

  1. The CPython Interpreter: Downloaded directly from python.org, CPython is the standard reference implementation of Python written in C. During installation on Windows platforms, checking the option "Add python.exe to PATH" is critical. This registers Python binary directory paths into system Environment Variables, enabling global execution of python and pip commands from system terminals.
  2. Integrated Development Environments (IDEs):
    • PyCharm (JetBrains): A dedicated Python IDE available in a free Community Edition. PyCharm excels in automated virtual environment provisioning, robust visual debugging, static code analysis, and refactoring utilities.
    • Visual Studio Code (Microsoft): A lightweight extensible editor requiring the official Microsoft Python extension for debugging, linting, and terminal execution.

1.3 Creating Your First Python Program

Python source files are plain text files saved with the .py file extension. The primary output function in Python is the built-in print() function, which writes text output to the standard output stream (the console terminal).

Python Script — Hello World and Comments

# Comments provide human-readable documentation explaining complex logic or assumptions.

Whitespace and Indentation Rule: Python does not use curly braces ( {} ) or semi-colons ( ; ) to define code blocks or end statements. Code block relationships and execution scope are governed strictly by consistent indentation (4 spaces per level)!

Module 2: Variables & Fundamental Primitive Data Types

2.1 Memory Containers, References, and Variables

In computer programming, a Variable is a named reference stored in memory that points to a specific data value. In Python, variables are created automatically when assigned a value using the assignment operator ( = ). Unlike statically-typed languages where variable data types must be explicitly declared (e.g., int age = 25; ), Python utilizes Dynamic Typing, automatically inferring the variable's data type based on the value assigned to it at runtime.

Variable Naming Conventions (PEP 8 Style Guide)
  • Must start with a letter ( a-z, A-Z ) or an underscore ( _ ). Cannot start with numbers.
  • Can only contain alphanumeric characters and underscores ( a-z, 0-9, _ ).
  • Case-sensitive ( age , Age , and AGE are three distinct variable containers).
  • Should follow snake_case naming conventions (e.g., first_name , total_item_count ).
  • Cannot use reserved Python keywords (such as class , def , if , for , import ).

2.2 The 4 Fundamental Primitive Data Types

Python categorizes primitive values into four core data types:

Data Type Type Keyword Description & Characteristics Example Literals
String str A contiguous sequence of characters enclosed within double quotes ( "..." ) or single quotes ( '...' ). Used for names, descriptions, and textual data. "Bro" , 'pizza' , "user@example.com"
Integer int Whole numbers without fractional decimal points (positive, negative, or zero). Used for precise counts, indices, and quantities. Supports exact arithmetic. 25 , 3 , 30 , -100
Float float Floating-point numbers containing fractional decimal components. Used for precise scientific measurements, financial amounts, GPAs, and distances. 10.99 , 3.2 , 5.5 , 3.14159
Boolean bool Binary logical state flags taking strictly one of two state values: True or False (Must be capitalized). Essential for conditional branching. True , False

Module 3: Type Casting Mechanics & User Input Handling

3.1 Type Casting Explained

Type Casting is the explicit process of converting a value or variable from one data type to another. Type casting is required because Python enforces strong typing rules: attempting mathematical calculations between incompatible data types (such as adding a string to an integer) triggers runtime errors.

Python provides native type casting functions:

  • str(value) : Converts a value into its textual string representation.
  • int(value) : Converts a value into an integer (truncates floating-point decimals without rounding).
  • float(value) : Converts a value into a floating-point number.
  • bool(value) : Converts a value into a boolean ( True or False ).

3.2 Inspecting Data Types with type()

The built-in type() function inspects and returns the active data class of any object or variable.

Python Script — Type Conversion and Inspection 
name = "Bro Code"
age = 25
gpa = 3.2
is_student = True

# Inspecting Data Types
print(type(name))         # Output: <class 'str'>
print(type(age))          # Output: <class 'int'>
print(type(gpa))          # Output: <class 'float'>
print(type(is_student))    # Output: <class 'bool'>

# Float to Int Conversion (Truncates decimal portion)
gpa_integer = int(gpa)
print(gpa_integer)        # Output: 3

# Int to Float Conversion
age_float = float(age)
print(age_float)          # Output: 25.0

# Int to String Conversion
age_str = str(age)
print(type(age_str))      # Output: <class 'str'>
print(age_str + "1")      # Output: "251" (Text concatenation, not addition!)

# String to Bool Conversion (Truthy vs Falsy Behavior)
# Non-empty strings evaluate to True; empty strings evaluate to False
print(bool("Bro"))        # Output: True
print(bool(""))           # Output: False (Useful for validating empty user inputs!)

3.3 Accepting User Input via input() Function

The input() function prompts the user to enter data via the console terminal. Program execution halts until the user types their input and presses Enter.

CRITICAL Architectural Principle — input() Return Type: The input() function ALWAYS returns user data as a String ( str ), regardless of whether the user typed numbers! Attempting mathematical calculations on raw input() values will trigger a runtime TypeError or produce incorrect string concatenation. Numerical inputs MUST be explicitly wrapped inside int() or float() type casting!

Python Script — Accepting & Type Casting User Input 
# Basic Text Input

print(f"Hello {name}!")

# Numeric Input with Nested Type Casting
# Convert raw string input directly into Integer

age += 1 # Increment integer safely
print(f"Happy Birthday! Next year you will be {age} years old.")

# Float Input for Geometry Calculations
length = float(input("Enter rectangle length (cm): "))
width = float(input("Enter rectangle width (cm): "))
area = length * width

print(f"The calculated area is: {area} cm²")

Module 5: Decision Making — Conditional Statements & Match-Case

5.1 Conditional Execution Pipeline ( if , elif , else )

Conditional statements evaluate boolean expressions sequentially from top to bottom. The code block associated with the first condition evaluating to True is executed, and all subsequent conditional branches are skipped entirely.

Python Script — Multi-Branch Conditional Execution 
age = int(input("Enter your age: "))

if age >= 100:
    print("You are too old to sign up!")
elif age >= 18:
    print("You are now successfully signed up!")
elif age < 0:
    print("You haven't been born yet!")
else:
    print("You must be 18+ to sign up.")

Condition Evaluation Order Rules: Place more restrictive or higher threshold conditions at the top of an if-elif chain. Checking elif age >= 18: before if age >= 100: would cause a 105-year-old user to match the >= 18 branch first, preventing the centenarian check from ever executing!

5.2 Comparison Operators

Comparison operators evaluate expressions and return boolean True or False values:

  • == : Equality check (Checks if left value equals right value. Do not confuse with single = assignment!).
  • != : Inequality check (Checks if left value does not equal right value).
  • > / < : Greater than / Less than.
  • >= / <= : Greater than or equal to / Less than or equal to.

5.3 Python 3.10 Pattern Matching ( match-case Statements)

Introduced in Python 3.10, the match-case statement provides a structured pattern-matching syntax acting as a clean alternative to long chains of elif equality comparisons (similar to switch statements in C/Java). The underscore ( case _ ) acts as the default wildcard fallback match.

Python Script — Match-Case Syntax Implementation 
def get_day_of_week(day_num):
    match day_num:
        case 1:
            return "Sunday"
        case 2:
            return "Monday"
        case 3:
            return "Tuesday"
        case 4:
            return "Wednesday"
        case 5:
            return "Thursday"
        case 6:
            return "Friday"
        case 7:
            return "Saturday"
        case _: # Wildcard default match
            return "Invalid day number!"

print(get_day_of_week(1)) # Output: "Sunday"
print(get_day_of_week(9)) # Output: "Invalid day number!"

# Combining Multiple Pattern Matches using Bitwise OR (|)
def is_weekend(day_name):
    match day_name.capitalize():
        case "Saturday" | "Sunday":
            return True
        case "Monday" | "Tuesday" | "Wednesday" | "Thursday" | "Friday":
            return False
        case _:
            return False

print(is_weekend("Sunday")) # Output: True

Module 6: Logical Operators & Conditional Expressions

6.1 Logical Operators ( or , and , not )

Logical operators allow multiple boolean conditions to be combined together:

  • or : Evaluates to True if at least one condition is true. Short-circuits immediately upon encountering the first true condition.
  • and : Evaluates to True only if ALL conditions are true. Short-circuits immediately upon encountering the first false condition.
  • not : Inverts the boolean result (turns True to False , and False to True ).
Python Script — Logical Operator Chains & Chained Comparisons 
temp = 25
is_raining = False
is_sunny = True

# 1. OR Operator (At least one condition TRUE)
if temp > 35 or temp < 0 or is_raining:
    print("Outdoor event is CANCELLED!")
else:
    print("Outdoor event is still SCHEDULED.")

# 2. AND Operator (ALL conditions must be TRUE)
if temp >= 28 and is_sunny:
    print("It is hot and sunny outside! ")

# 3. Python Chained Comparison Syntax Shortcut
# Equivalent to: (temp < 28 and temp > 0 and is_sunny)
if 0 < temp < 28 and is_sunny:
    print("It is warm and sunny outside!")

# 4. NOT Operator (Inverts boolean logic)
if not is_raining:
    print("It is not raining. Enjoy your day!")

6.2 Conditional Expressions (Ternary Operator Shorthand)

A Conditional Expression is a concise inline shortcut for evaluating an if-else statement in a single line. It evaluates a condition and assigns or returns one of two values.

X if condition else Y
(Returns value X if condition is True ; otherwise returns value Y ).
Python Script — Conditional Expressions Examples 
num = 5
age = 20
user_role = "admin"

# Check Positive/Negative
result = "Positive" if num > 0 else "Negative"
print(result) # Output: "Positive"

# Check Even/Odd using Modulus
parity = "Even" if num % 2 == 0 else "Odd"
print(parity) # Output: "Odd"

# Age Status Evaluation
status = "Adult" if age >= 18 else "Child"
print(status) # Output: "Adult"

# Access Level Assignment
access_level = "Full Access" if user_role == "admin" else "Limited Access"
print(access_level) # Output: "Full Access"

Strings in Python are immutable sequence objects featuring a rich built-in method library:

String Method Return Type Description & Purpose

7.2 String Indexing & Slicing Syntax

Slicing extracts sub-sequences from a string using indexing bracket syntax: string[start:end:step] .

Slicing Field Rules:

  • start : Inclusive starting index (Defaults to 0 if omitted).
  • end : Exclusive ending index (Defaults to string length if omitted).
  • step : Index increment step size (Defaults to 1 ). Negative step ( -1 ) iterates backwards!
Python Script — String Slicing & Negative Indexing 
credit_number = "1234-5678-9012-3456"

# Fetch First Character (0-indexed)
print(credit_number[0]) # Output: "1"

# Slice First 4 Digits (Indices 0 to 3; end index 4 is exclusive)
print(credit_number[0:4]) # Output: "1234"
print(credit_number[:4])  # Output: "1234" (Omitting start defaults to 0)

# Slice Characters from Index 5 to End
print(credit_number[5:])  # Output: "5678-9012-3456"

# Negative Indexing (Negative numbers count backwards from end)
print(credit_number[-1]) # Output: "6" (Last character)
last_four = credit_number[-4:]
print(f"XXXX-XXXX-XXXX-{last_four}") # Output: "XXXX-XXXX-XXXX-3456"

# Step Modifier (Extract every 2nd character)
print(credit_number[::2]) # Output: "13-6891-46"

# Reversing a String using Step -1
reversed_str = credit_number[::-1]
print(reversed_str) # Output: "6543-2109-8765-4321"

7.3 Advanced Format Specifiers inside F-Strings

Format specifiers dictate visual formatting of numeric output inside F-Strings using colon syntax ( {value:flags} ):

Python Script — Format Specifier Demonstrations 
price1 = 3.14159
price2 = -987.65
price3 = 1200.50

# Decimal Precision (.2f = 2 decimal places float)
print(f"Price: ${price1:.2f}") # Output: "Price: $3.14"

# Allocating Field Width Padding (:10 = Align within 10-character width)
print(f"Price: ${price3:10.2f}") # Output: "Price: $   1200.50"

# Zero Padding (:010 = Fill leading width with zeros)
print(f"Price: ${price1:010.2f}") # Output: "Price: $0000003.14"

# Text Alignment (< = Left, > = Right, ^ = Center)
print(f"Price: ${price1:<10.2f}") # Left aligned
print(f"Price: ${price1:^10.2f}") # Center aligned

# Positive/Negative Sign Display (+ = Show + for positive)
print(f"Price: {price1:+.2f}") # Output: "+3.14"
print(f"Price: {price2:+.2f}") # Output: "-987.65"

# Thousands Separator (, = Insert commas into thousands)
print(f"Price: ${price3:,.2f}") # Output: "Price: $1,200.50"

Module 8: Loops & Iteration Mechanics — While, For & Nested Loops

8.1 while Loops & Sentinel Control

A while loop repeatedly executes a block of code as long as a specified condition evaluates to True . It is primarily used when the exact number of iteration cycles is unknown ahead of time (such as validating user input).

Python Script — Input Validation with While Loops 
# Input Validation: Continuously re-prompt until valid name provided
name = input("Enter your name: ")
while name == "":
    print("You did not enter your name!")
    name = input("Enter your name: ") # Sentinel update to break loop
print(f"Hello {name}")

# Numeric Validation Example
age = int(input("Enter your age: "))
while age < 0:
    print("Age cannot be negative!")
    age = int(input("Enter your age: "))
print(f"You are {age} years old.")

8.2 for Loops & Range Mechanics

A for loop iterates over a fixed sequence or iterable object (ranges, strings, lists). The built-in range(start, stop, step) function generates integer sequences:

Python Script — For Loop Variations 
# Iterate over Range 1 to 10 (stop number 11 is EXCLUSIVE)
for x in range(1, 11):
    print(x) # Prints 1 through 10

# Iterate Backwards using reversed() or negative step
for x in reversed(range(1, 11)):
    print(x) # Prints 10 down to 1
print("HAPPY NEW YEAR!")

# Custom Step Increments (Count by 2s)
for x in range(1, 11, 2):
    print(x) # Prints 1, 3, 5, 7, 9

8.3 Loop Control Statements ( break , continue , pass )

  • continue : Immediately skips the remainder of the current iteration and jumps to the next cycle.
  • break : Immediately terminates the loop entirely, jumping execution to code outside the loop block.
  • pass : A null-op placeholder statement used when syntactically required, performing no action.
Python Script — Continue and Break Statements 
# Skip unlucky number 13 using continue
for x in range(1, 21):
    if x == 13:
        continue # Skip 13 entirely
    print(x)

# Terminate loop prematurely using break
for x in range(1, 21):
    if x == 13:
        break # Exit loop completely upon reaching 13
    print(x)

8.4 Nested Loops & Grid Matrix Generation

A Nested Loop consists of a loop placed inside the body of an outer loop. The inner loop completes all of its iterations for every single iteration cycle of the outer loop.

Python Script — Printing Character Grid with Nested Loops 
rows = int(input("Enter number of rows: "))
cols = int(input("Enter number of columns: "))
symbol = input("Enter symbol to use: ")

for x in range(rows):         # Outer loop controls rows
    for y in range(cols):     # Inner loop controls columns
        print(symbol, end="") # Prevent newline between columns
    print()                   # Print newline after completing each row

Module 9: Python Data Structures — Lists, Sets, Tuples & Dictionaries

9.1 Comparative Overview of Core Collections

Python provides four native general-purpose collection data structures, categorized by four structural properties: Ordering, Mutability, Duplicate Permissibility, and Indexing Support.

Collection Syntax Brackets Ordered? Mutable? Duplicates? Primary Use Case & Characteristics
List Square [ ] Yes Yes Yes General-purpose dynamic sequences. Highly flexible; supports appending, insertion, removal, and sorting.
Set Curly { } No Yes (Add/Remove) No Unordered unique elements. Fast membership testing ( O(1) time complexity) and automatic duplicate elimination.
Tuple Parentheses ( ) Yes No (Immutable) Yes Read-only fixed sequences. Faster execution performance and lower memory footprint than lists. Safe against accidental modification.

  • **kwargs (Keyword Unpacking): Prefixed with double asterisks ( ** ). Packs arbitrary keyword arguments into a Dictionary.

13.2 Variable Scope & The LEGB Resolution Rule

Variable Scope defines the accessibility boundary of a variable. Python resolves variable identifiers sequentially using the LEGB Rule order:

  1. L — Local Scope: Variables declared inside the body of the active function.
  2. E — Enclosed Scope: Variables declared within an outer wrapping function (in nested functions).
  3. G — Global Scope: Variables declared at the top-level script file level outside any function.
  4. B — Built-in Scope: Pre-loaded language keywords and built-in identifiers (e.g., len , range , print ).

15.1 Context Managers & File Modes

The safest pattern for file manipulation is the with open(path, mode) as file: context manager syntax. It guarantees that physical system file handles are closed automatically upon block exit, preventing resource leaks or file lock errors.

18.1 Class Inheritance Architecture

18.3 Polymorphism & Duck Typing

Polymorphism ("many forms") allows objects of different classes to respond to identical method calls based on shared interface signatures. Python utilizes Duck Typing: "If it looks like a duck and quacks like a duck, it's treated as a duck." Object identity depends on method presence rather than rigid explicit class inheritance.

Python Script — Inheritance, super(), and Polymorphism

class Shape:
    def __init__(self, color, is_filled):
        self.color = color
        self.is_filled = is_filled

# Child Subclass 1
class Circle(Shape):
    def __init__(self, color, is_filled, radius):
        super().__init__(color, is_filled) # Delegate parent initialization
        self.radius = radius

    def area(self):
        import math
        return math.pi * (self.radius ** 2)

# Child Subclass 2
class Square(Shape):
    def __init__(self, color, is_filled, side):
        super().__init__(color, is_filled)
        self.side = side

    def area(self):
        return self.side ** 2

# Demonstrating Polymorphism
shapes = [Circle("Red", True, 5), Square("Blue", False, 4)]

    # Identical area() method call executed on distinct objects!
    print(f"{shape.color} Shape Area: {shape.area():.2f}")

19.1 Encapsulation & The @property Decorator
